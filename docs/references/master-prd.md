### 6.1 על מה היא מבוססת

- **A:** טוקנים מלאים מתוך ה-CSS של האתר (כפי שמופיעים ב-PRD).
- **B:** הקובץ לא כולל צבעים. הערכים כאן **נדגמו מהפיקסלים** של צילום מסך של `game-changer.brainai.co.il/cohort` (24.11.2026), עם סקריפט שמוצא את הצבע הדומיננטי בכל אזור ולא בעין.
  - **דיוק:** צילום מסך ב-Mac עובר המרת פרופיל צבע ודחיסת WebP, ולכן הערכים עלולים לסטות ב-1 עד 3 יחידות לכל ערוץ. שני ערכים יצאו זהים בדיוק לצבעי Tailwind v4 (`#E7000B` = red-600, `#FAFAFA` = neutral-50). זה מחזק את הדיוק, ומרמז (לא מוכיח) שהאתר בנוי על Tailwind v4.
  - **לערכים מדויקים:** ב-Chrome על האתר, DevTools > Console, להריץ את הקוד שלמטה. הפלט מועתק ללוח, ואז מדביקים אותו כאן.

```js
// מדפיס את כל משתני ה-CSS ואת הפונט של האתר (כולל משתנים בתוך @layer / @media)
const vars = {};
const walk = rules => { for (const r of rules) {
  if (r.cssRules) walk(r.cssRules);
  if (r.style && /:root|\.dark|data-theme/.test(r.selectorText || ''))
    for (const p of r.style) if (p.startsWith('--')) vars[`${r.selectorText} ${p}`] = r.style.getPropertyValue(p).trim();
} };
for (const s of document.styleSheets) { try { walk(s.cssRules); } catch (e) {} }
copy(JSON.stringify({ font: getComputedStyle(document.body).fontFamily, vars }, null, 1));
console.log('הועתק ללוח:', Object.keys(vars).length, 'משתנים');
```

### 6.6 טיפוגרפיה ומידות

- **פונט:** A משתמש ב-`Polin, Heebo`. את הפונט של B אי אפשר לזהות בוודאות מפיקסלים, והקוד בסעיף 6.1 יחשוף אותו. למיטב ידיעתי Polin הוא פונט מסחרי, וצריך לבדוק רישיון לשימוש ב-Web. ההמלצה: **Heebo** (Google Fonts, חינמי, עברית + לטינית) כפונט ראשי (⚠️ #52).
- **מספרים:** `font-variant-numeric: tabular-nums` למונים, אחוזים וספירות לאחור, כדי שהספירה עד שניות (B) לא תקפוץ.
- **סולם (מ-A):** H1 30/800, H3 20/700, Body 16/400, כפתור 15/600, תג 12/700. בתג של 12px להשתמש רק בצבעי `on-*-subtle` (כולם מעל 6:1).
- **רדיוס:** כרטיס 16px, כפתור 12px, גלולה 9999px (A). B נראה עקבי עם זה: כפתורים וכרטיסים מעוגלים, פריט פעיל ב-Sidebar כגלולה.
- **אייקונים:** קו דק ומעוגל (B), סגנון Lucide, שהיא ברירת המחדל של shadcn/ui. A משתמש ב-Material Symbols.

### 8.3 מסקנה

**החלטה #2 עומדת: Next.js + Supabase.** אף פתרון מדף לא מכסה את מה שמבדל את ה-MVP:

1. תמלול + ציר זמן + חיפוש בתוך תמלולים
2. הערות שקשורות לרגע בסרטון
3. דיון שאלות-תשובות בשיעור עם תשובה נבחרת

5. מנוע כללים לתעודה + עמוד אימות
6. פלטה ועיצוב משלך (סעיף 6)
7. בסיס ל-RAG ולסוכן AI בשלב 2, שדורש גישה ישירה לנתונים

**חריג אחד שווה שקילה:** אם יש לך תלמידים שמחכים **עכשיו**, מועדון יכול להיות פתרון ביניים זול (127-197 ₪ לחודש) לחודשיים-שלושה עד שה-MVP מוכן. כך מאמתים ביקוש ומחיר לפני שמשקיעים בפיתוח. התנאי: ייצוא של רשימת החברים, כדי להעביר אותם אחר כך.

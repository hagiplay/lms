## החלטות ארכיטקטורה (נקבעו בזמן המימוש)

| נושא | החלטה | למה |
| --- | --- | --- |
| Framework | Next.js 15.5 (App Router) + React 19 + TypeScript strict | יציב ומוכר. שדרוג ל-16 = משימה נפרדת (P5.8) |
| עיצוב | Tailwind v4 + טוקנים מסעיף 6.7, RTL, Heebo מקומי (`@fontsource`) | בלי תלות ב-Google Fonts בזמן build |
| גישה לנתונים | Drizzle ORM + `postgres` מצד השרת בלבד (Server Components / Server Actions) | נבדק מול Postgres מקומי. הרשאות נאכפות בשכבה אחת (`lib/authz`) עם בדיקות |
| Supabase | Postgres מתארח + Auth (OTP במייל + Google) + Storage | כמו #37. RLS **מופעל בלי policies** על כל הטבלאות: ה-Data API של Supabase חסום לגמרי, והגישה היא רק דרך השרת |
| התחברות בפיתוח | כשאין משתני Supabase: מסך "התחברות פיתוח" עם משתמשי seed, עוגייה חתומה ב-HMAC. חסום ב-production | אפשר לפתח ולבדוק בלי פרויקט Supabase |
| וידאו | Bunny Stream iframe עם Token Authentication; HTML5 `<video>` לקישור ישיר | #12 |
| תעודה | עמוד HTML להדפסה/שמירה כ-PDF + עמוד אימות ציבורי | PDF בצד שרת עם עברית דורש shaping; עמוד הדפסה פותר את זה בלי תלות |
| סליקה | Webhook גנרי חתום ב-HMAC, עם idempotency. Adapter לספק ספציפי אחרי שתבחר ספק | #5. הספק עוד לא נבחר |
| מייל | Resend דרך HTTP כשיש מפתח; אחרת לוג | |
| חיפוש | `ILIKE` + אינדקס `pg_trgm` | FTS של Postgres לא מטפל בתחיליות עבריות (ה, ו, ב, ל) |

**מה צריך ממך כדי לסגור את ה-MVP:** P5.4 עד P5.7. כל אחד דורש חשבון ומפתחות שרק את/ה יכול/ה ליצור. המפתחות נכנסים רק למשתני סביבה, לא לקוד ולא לצ'אט. פירוט ב-README.

**תיקונים שהבדיקות מצאו בדרך:**
- `--text-muted` שונה מ-`#64748B` ל-`#5B677A`: הישן נכשל על רקע `surface-muted` (4.26) ו-`primary-subtle` (4.04). החדש 4.86 ומעלה על כל רקע בהיר.
- יחידה נעולה הוצגה בשקיפות (`opacity`) שהורידה את הניגודיות מתחת לסף. הוחלף ברקע אפור + אייקון מנעול.
- הודעת "המשימה הושלמה" הופיעה ממצב אופטימי לפני אישור השרת. עכשיו רק ממצב שהשרת אישר.
- שדות תאריך בניהול נפרשו לפי אזור הזמן של השרת (UTC), כלומר מפגש של 19:00 היה נשמר כ-21:00. עכשיו נפרשים כשעון ישראל, כולל שעון קיץ.
- שגיאות ולידציה בניהול היו נבלעות ב-production (Next מסתיר הודעות של שגיאות שנזרקות מ-Server Actions). עכשיו מוחזרות ומוצגות.
